# KPL 2K 文字系统编辑说明

文字分两层，所有文案都是数据文件，改完即生效（重新模拟即可看到）。

## 文件

| 文件 | 管什么 |
|---|---|
| `templates.json` | 局内战报素材 + 赛季故事素材（体系/英雄/开局/事件/结局/翻盘/爆冷/淘汰/加冕/梗/开赛/轮次/决赛/冠军/终章） |
| `player_flavor.json` | 选手名场面彩蛋（按场景分桶：开场/名场面/翻盘/决赛/夺冠/遗憾/低谷） |
| `team_flavor.json` | 战队外号库（按队伍名关键字匹配，故事开场引用一条） |

## templates.json 的占位符（{} 会被模拟结果替换）

| 占位符 | 含义 |
|---|---|
| `{team_a}` / `{team_b}` | 系列赛双方队名 |
| `{team}` / `{opp}` | 当前事件主角队 / 对手队 |
| `{player}` | 事件主角选手名 |
| `{system}` | 阵容体系（从 systems 里抽） |
| `{system_a}` / `{system_b}` | BP 段双方体系 |
| `{hero_a1}` / `{hero_a2}` / `{hero_b1}` / `{hero_b2}` | BP 段双方英雄（从 heroes 各分路抽） |
| `{hero_b}` | 对手英雄（从 heroes 对应分路抽） |
| `{objective}` | 地图资源（暴君/主宰/风暴龙王…） |
| `{minute}` | 事件发生分钟（8–16 随机） |
| `{score_a}` / `{score_b}` | 当前系列赛比分 |
| `{year}` / `{season}` | 年份 / 赛季名 |
| `{roster}` | 玩家阵容选手列表 |
| `{story}` | 冠军句里的一句话总结 |

## 各分路可用的英雄池（heroes）

对抗路 / 打野 / 中路 / 发育路 / 游走，各 12 个。战报里 `{hero_b}` 默认从"发育路"抽，可自行调整代码或加字段。

## player_flavor.json 的写法

```json
"选手名": {
  "开场": ["句子1", "句子2"],
  "名场面": ["句子1"],
  "翻盘": ["句子1"],
  "决赛": ["句子1"],
  "夺冠": ["句子1"],
  "遗憾": ["句子1"],
  "低谷": ["句子1"]
}
```

- 场景键可省略，缺省时自动退回"名场面"；
- 同一句在一个故事里只出现一次；
- 想给选手加人设：加个新名字的键即可，不需要改代码。
- "低谷"是状态不好时的小局文案，某轮丢过小局时会自动插进故事。
- 彩蛋抽选手会自动均衡：同一场比赛（轮次/总决赛）内不重复，相邻场次尽量轮换。
- 黑称/梗的筛选红线：攻击长相身高、疾病侮辱、假赛指控、低俗擦边的一律不进库。

## 规则

1. 必须是合法 JSON（逗号、引号别错）；建议句子里不要写英文逗号。
2. 句子保持简短（15–35 字最佳），太长会像作文。
3. 需要插入模拟结果的地方用上面的占位符，别的文字随便写。
4. 想先看效果：`python tools/sim_engine.py --season KCC2026 --roster "Fly:2023S1;小胖:2023S1;向鱼:2023S1;妖刀:2023S1;帆帆:2023S1" --story`
5. 文案走梗化风格：把选手黑称/社区梗揉进文字，让玩家会心一笑；名场面要有真实事件做底，允许俏皮演绎，但不要硬编。

## 建议

- 梗要用大家看得懂的，太私人的梗传播不开；
- 夺冠/遗憾台词可以多写几版，让不同结局更有情绪差；
- 新增选手彩蛋前先核实名场面（比赛时间/比分/英雄），网上搜不到依据的素材不要写；
- 新增英雄/体系会同时影响所有战报的随机组合。
